# Mechanic Job System

A comprehensive mechanic job system for FiveM servers.

## Features

- Vehicle repair system for mechanics
- Vehicle washing system for mechanics
- Database integration to track vehicle health

## Requirements

- FiveM server
- QBCore framework
- oxmysql

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `ensure MechanicJobSystem` to your server.cfg file.

## Usage

### For Players

- Join the server and select the mechanic job.
- Use the repair and washing stations to maintain vehicles.

### For Admins

- Configure the `config.lua` file to adjust costs and times.
- Use the database to manage vehicle health records.

## Configuration

Edit the `config.lua` file to customize:

- Blip settings for the mechanic job
- Repair and washing costs
- Repair and washing times
